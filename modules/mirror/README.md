# Channel Mirror Commands

Want a channel to mirror all its messages receieved into another one? Use the `~mirrorchan` command to set it up!

To stop mirroring, use the `~unmirrorchan` command.

You can also list all current mirrors with the `~listmirrorchan` command.

Only server moderators can use these commands.

Use `~help Channel Mirror` to get more information on how to use these commands.
